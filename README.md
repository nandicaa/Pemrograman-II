# MedReminder (Pemrograman II)

Aplikasi pengingat minum obat untuk pasien dan pemantauan kepatuhan untuk pengawas.

## Struktur Folder
- medreminder-vscode/ — Server API Node.js (Express + MySQL). Salin .env.example menjadi .env, jalankan 
pm install lalu 
pm start.
- medreminder-xampp/ — Halaman web pasien, website pengawas, dan skema database (database/schema.sql). Salin ke C:\xampp\htdocs\medreminder\.
